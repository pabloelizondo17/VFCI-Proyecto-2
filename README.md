# VFCI-Proyecto-2: Verificación del UART 16550 con UVM

**Curso:** Verificación Funcional de Circuitos Integrados (EL5811)  
**Institución:** Tecnológico de Costa Rica (TEC).
**Semestre / Año:** II Semestre 2026  


## Descripción del Proyecto

Este repositorio contiene el desarrollo del **Segundo Proyecto** para el curso **Verificación Funcional de Circuitos Integrados (EL5811)**. El proyecto comprende el diseño e implementación de un ambiente de verificación con una arquitectura basada en UVM 1.2.
